# Moore-2026-MentorshipDocs

SUPPLEMENTAL INFORMATION
All supplemental materials are adaptable templates. Targets and timelines are illustrative, should be
adapted to discipline, career stage, and institutional context, and are not validated assessment
instruments or universal performance standards.

Supplemental Guide 1. Track-Specific Career Development Guide with implementation guidance for
research, clinical, and physician-scientist faculty.

Supplemental Guide 2. Mentorship Models: implementation guidance for seven models, including
structure, staffing, resource considerations, and evaluation evidence.

Supplemental Table 1. 90-Day Scholarship and Mentoring Quick Start Guide with milestones for
mentees and mentors during relationship formation.

Supplemental Table 2. 24-Month Mentorship and Sponsorship Guide with illustrative track-specific
timelines, indicators, and common pitfalls.

Supplemental File 1. Individual Development Plan (IDP) template with sections for self-assessment,
mentoring network and sponsorship, annual objectives, career milestones, current barriers and
resources needed, career goals with quarterly milestones, and a review log.

Supplemental File 2. Mentorship Agreement template defining roles, responsibilities, meeting
frequency, communication, confidentiality, success criteria, and conflict-resolution routes, including a
neutral third party.

Supplemental File 3. Mentor Review Checklist (rapid first pass) for formative feedback on manuscripts
and grant applications, with paper-specific and grant-specific items.

Supplemental File 4. Writing Pod Charter, an optional template for peer accountability groups.

Supplemental File 5. Submission-Readiness Rubric for journal manuscripts, intended for formative
feedback and not for predicting editorial decisions.

Supplemental File 6. Formative Grant Review Rubric for internal mock review of grant applications; it
is not an NIH scoring instrument.

Supplemental File 7. Mentorship Tracking System (Excel workbook) with (1) a Mentee Tracker for
IDPs, meetings, productivity, and annual metrics and (2) a Mentor Sponsorship Tracker for
documenting sponsorship activities and their distribution.
